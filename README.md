### 🚀 Featured Projects

#### 🎥 [StreamChatVideo](https://github.com/ShipWithKartik/StreamChatVideo)
A MERN language-exchange chat & video app. Backend built on Express + MongoDB (Mongoose) with the Stream Chat SDK, JWT cookie-based auth, and Cloudinary for avatar uploads. Core features include a friend request system, language-exchange "rooms" that pair users by native/learning language via Stream "team" channels, user search & discovery, and profile onboarding.
`Node.js` `Express.js` `MongoDB` `React` `Stream Chat SDK`

#### 🔎 [SmartSearch (SmartFilteringRAG)](https://github.com/ShipWithKartik/SmartSearch)
A Retrieval-Augmented Generation (RAG) system with a multi-step pipeline that uses an LLM to pre-filter metadata *before* running vector search — improving retrieval precision over naive RAG. Built on LangChain and MongoDB Atlas Vector Search, with a Streamlit UI, conversational memory, automated metadata extraction, and an evaluation suite.
`LangChain` `MongoDB Atlas Vector Search` `Streamlit` `Python`

#### 🛒 Smart Product Re-Ranking for E-Commerce
A Learning-to-Rank system built on the Retailrocket dataset (2.7M+ real interaction events). Reframed as an LTR problem using XGBRanker, with temporal train/test splitting and recency-decay feature engineering. Achieved a measurable improvement in top-10 precision (NDCG@10 / MAP@10, statistically significant at p < 0.05).
`Python` `XGBoost` `scikit-learn` `Pandas`

#### 🏏 Hand Gesture Cricket Game
A webcam-based cricket game controlled entirely through hand gesture recognition, built with OpenCV.
`Python` `OpenCV`

#### 🖥️ Unidesk
A front-end project built with vanilla HTML, CSS, and JavaScript — no frameworks.
`HTML` `CSS` `JavaScript`
